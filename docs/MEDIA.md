# Documentation media

The README uses English captures from the actual Plot Electron app, with an illustrative notification-service repository and a prepared saved overview. No live GitHub account, real access token or AI request is used. The demo does not demonstrate AI generation speed.

On macOS, with dependencies installed and FFmpeg available:

```sh
npm run capture:docs
```

The script creates an isolated temporary profile and Git repository, captures the unmodified application UI at 1600 × 1120, then removes its temporary data. It never opens the normal Plot profile. GitHub responses are intercepted inside this temporary app process; live network fetches are blocked. AI analysis is not started.

Outputs in `docs/media/`:

- `pull-request.png`: code diff and AI overview.
- `change-map.png`: before-and-after architecture comparison.
- `local-changes.png`: uncommitted retry policy changes.
- `plot-demo.mp4`: an English walkthrough of these views.

The source example and saved overview are maintained in `e2e/demo-fixture.mjs`. Keep their explanations consistent with the example code. These example files are documentation fixtures, not Plot's notification implementation.

The README uses GitHub's native video attachment for inline playback and links to the tracked MP4 as a download fallback. GitHub's regular repository file page does not provide the inline player. After regenerating the video, upload the new MP4 using GitHub's Markdown attachment control and replace the attachment URL in the README. No issue or comment needs to be published to obtain that URL. Do not rely on a repository-relative HTML video tag rendering in all Markdown viewers.

The app icon is generated by `npm run icons` on macOS using the Swift command-line tools. Source and platform assets live in `build/`; see `build/generate-icon.swift`.
