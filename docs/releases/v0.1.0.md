# Plot 0.1.0

The first preview of Plot, a Mac app for understanding pull requests and local code changes.

- Browse GitHub pull requests or open one by URL, including GitHub Enterprise Server.
- Read side-by-side or unified diffs with a changed-files tree and configurable keyboard shortcuts.
- Inspect local branch changes, uncommitted edits and untracked files with automatic refresh.
- Use optional Claude Code or Codex CLI overviews, with code references and before-and-after diagrams.
- Choose English or Korean, separate overview language settings, Light/Dark/Darcula themes and code fonts.

## Install

Requires macOS 13+ and Git. Choose `arm64` for Apple Silicon or `x64` for Intel. Open the DMG and drag Plot into Applications. Verify the download against `SHA256SUMS.txt` if needed.

GitHub is required for PRs. Local changes work without an account. AI overviews require a compatible installed tool and your own sign-in or API key; usage is governed by your provider's plan and pricing.

## Preview limits

Windows and Linux are not supported. AI overviews currently cover pull requests only. Comments, approvals and merging stay on GitHub. AI explanations may be incorrect or incomplete; inspect the cited code and displayed analysis scope. Updates are downloaded manually or through the project tap once published; there is no in-app updater.

See the [user guide](https://github.com/gentledev10/plot/blob/main/docs/GUIDE.md) and report reproducible problems in [Issues](https://github.com/gentledev10/plot/issues/new/choose).
